# Лабораторна 2 — медіаплеєр

```bash
python make_samples.py   # тестові файли в media/ (потрібен ffmpeg)
python main.py           # або python main.py media/testcard.mp4 https://…/stream.m3u8

```

Гарячі клавіші: Пробіл — пуск/пауза, S — стоп, ← → — ±10 с, ↑ ↓ — гучність, M — без звуку, N / P — наступний / попередній, F — повний екран, Ctrl+O — файл, Ctrl+U — URL.
